# Тембр

Локальный преобразователь голоса на RVC. Браузер захватывает микрофон,
локальный Python-сервер конвертирует звук на NVIDIA GPU и отправляет его
в выбранное устройство вывода.

> Проверено на Windows и NVIDIA RTX 4060 Ti: CUDA-модель обрабатывает поток
> 400-миллисекундных аудиочанков через WebSocket smoke-тест. Реальную задержку
> с микрофоном и качество конкретного голоса нужно проверить на своей модели
> и аудиоустройстве.

## Требования

- Windows 10/11 x64.
- Python 3.11 x64 (`py install 3.11`, если `py -3.11 --version` его не находит).
- NVIDIA GPU с актуальным драйвером. CPU-only запуск намеренно не поддерживается.
- Visual Studio Build Tools с компонентом **Desktop development with C++**:
  `fairseq` собирает C++-расширение при первой установке.
- Chrome или Edge для выбора аудиовыхода. Firefox может использовать только
  системное устройство вывода.

## Запуск

1. Положи RVC `.pth` и, если он есть, соответствующий `added_*.index` в
   `backend/models/`. Файлы голосовых моделей не входят в репозиторий; проверь,
   что у тебя есть право использовать их.
2. Запусти `run.bat`. При первом запуске скрипт создаст Python 3.11 окружение,
   поставит закреплённые зависимости и CUDA-сборку PyTorch. Загрузка PyTorch
   занимает несколько гигабайт. После загрузки модели сервер сам откроет UI.
3. Разреши браузеру доступ к микрофону, выбери вход и выход, нажми **Старт**.

Для Discord: выбери `CABLE Input` как выход Тембра, а `CABLE Output` — как
микрофон в Discord. VB-CABLE устанавливается отдельно.

Если в `backend/models/` нет `nyamura-ru.pth`, сервер загрузит первый найденный
`.pth`. Голос также можно добавить кнопкой `+` в интерфейсе. Индекс необязателен.

## Что умеет текущая версия

- локальный FastAPI/WebSocket сервер и Web Audio интерфейс;
- выбор микрофона и аудиовыхода, уровни входа/выхода;
- сдвиг тона, индекс и входное/выходное усиление;
- загрузка RVC `.pth` и необязательного `.index`;
- ограничение очереди: если инференс медленнее входного 400-миллисекундного чанка, новые чанки
  пропускаются вместо накопления неограниченной задержки;
- локальный сервер слушает только `127.0.0.1:7860`.

## Проверка и диагностика

- `http://127.0.0.1:7860/health` показывает готовность сервера, активный голос
  и доступность CUDA.
- В нижней строке UI отображается время инференса одного чанка и число
  пропущенных чанков.
- Ошибки установки оставляют открытым окно `run.bat`; скопируй последние
  строки сообщения об ошибке.
- Чтобы проверить сервер без микрофона, запусти в отдельном окне:
  `backend\venv\Scripts\python.exe backend\smoke_test.py`. Тест отправит
  синтетический тон локально по WebSocket и выведет round-trip/инференс.

## Структура

```text
run.bat                       установка и запуск
backend/main.py               HTTP API и WebSocket аудио
backend/model_manager.py      загрузка RVC и адаптация аудио
backend/launcher.py           открытие браузера после готовности сервера
backend/requirements.txt      закреплённые Python-пакеты
backend/models/               локальные модели, исключённые из Git
frontend/                     интерфейс и AudioWorklet-процессоры
```
