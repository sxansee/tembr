# Tembr

Tembr — локальное desktop-приложение для преобразования голоса в реальном
времени на Windows. Студия открывается в отдельном окне Windows, захватывает
микрофон, обрабатывает звук RVC на NVIDIA GPU и выводит результат на выбранное
аудиоустройство. Обычный браузер для работы не нужен.

Микрофонный звук и голосовые модели обрабатываются на компьютере и не
отправляются в облако. При первом использовании `inferrvc` может скачать
вспомогательные RMVPE-веса в локальный кэш. Desktop-окно запускает Python-
аудиодвижок и закрывает его вместе с приложением.

## Возможности

- отдельное Windows-окно с библиотекой RVC-голосов и понятным состоянием эфира;
- выбор микрофона и устройства вывода, переключение устройств во время работы;
- входной и выходной уровни сигнала, время GPU-инференса и счётчик пропусков;
- настройка высоты тона, сходства голоса и уровней сигнала;
- русский, английский, испанский и немецкий языки интерфейса;
- три цветовые темы: графитовая, океаническая и ночная;
- значок в системном трее со сворачиванием окна и командами открытия/выхода;
- загрузка `.pth` и необязательного соответствующего `.index` из интерфейса;
- добавление `.index` к установленной модели и удаление модели из библиотеки;
- встроенная проверка GPU, модели, микрофона и виртуального кабеля;
- переключение преобразования кнопкой или `Ctrl + Shift + Space`;
- окно предоставляет доступ только к микрофону, только после команды «Начать».

## Требования

- Windows 10/11 x64.
- Python 3.11 x64 (`py install 3.11`, если `py -3.11 --version` его не находит).
- .NET 8 SDK или новее — нужен для сборки desktop-окна из исходников. В установщике уже есть готовое окно.
- Microsoft Edge WebView2 Evergreen Runtime. На Windows 11 он обычно уже
  установлен; при необходимости установи [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).
- NVIDIA GPU с актуальным драйвером. CPU-only запуск намеренно не поддерживается.
- Visual Studio Build Tools с компонентом **Desktop development with C++**:
  `fairseq` собирает C++-расширение при первой установке.

Установщик `Tembr-Setup` предложит создать ярлык на рабочем столе и в меню
«Пуск», включить запуск при входе в Windows и значок в трее. `run.bat` установит
Python-зависимости при первом запуске, а затем откроет студию. Первый запуск скачивает PyTorch CUDA
и собирает компоненты `fairseq`; для этого нужны интернет и несколько гигабайт
свободного места.

## Установка голоса и запуск

1. Положи RVC `.pth` и, если он есть, соответствующий `added_*.index` в
   `backend/models/`. Эти файлы намеренно не входят в GitHub-репозиторий:
   проверь право использовать выбранную модель.
2. Запусти Tembr из ярлыка или открой `run.bat`. Окно установки остаётся открытым,
   пока настраивается Python и CUDA/PyTorch.
3. В студии выбери модель, микрофон и устройство вывода, затем нажми
   **Начать преобразование**. Windows может попросить разрешить доступ к
   микрофону для приложения.

Если в `backend/models/` нет `nyamura-ru.pth`, движок загрузит первый найденный
`.pth`. Голос также можно добавить кнопкой **Добавить голос** в библиотеке.

Для Discord установи виртуальный кабель VB-CABLE отдельно. Выбери `CABLE Input`
как устройство вывода Tembr, а `CABLE Output` — как микрофон в Discord.

## Сборка desktop-окна отдельно

Из корня репозитория запусти:

```powershell
dotnet publish desktop/Tembr.Desktop.csproj -c Release -r win-x64 --self-contained true -o desktop/publish
```

Результат — `desktop/publish/Tembr.exe`. Для запуска ему нужны каталог
репозитория с `backend/venv` и установленный WebView2 Runtime.

Чтобы собрать установщик из исходников, установи Inno Setup и опубликуй desktop-
окно в `desktop/publish`, затем скомпилируй `installer/Tembr.iss`. GitHub Actions
собирает установщик и создаёт страницу релиза при публикации тега `v*`.

## Звук и производительность

Захват работает блоками по 200 мс. Если инференс GPU медленнее входного блока,
Tembr пропускает новый блок, чтобы задержка не накапливалась бесконечно. Студия
показывает время инференса блока и число пропусков. В локальном синтетическом
прогоне на RTX 4060 Ti первый чанк обработался за 5,65 с, следующие — за 224 и
78 мс. Первый вызов включает отложенную инициализацию; микрофон, аудиодрайвер и
выбранная модель влияют на задержку при реальной работе.

## Диагностика

- Раздел **Состояние системы** проверяет локальный движок, NVIDIA GPU, выбранную
  модель, микрофон и наличие виртуального кабеля.
- Desktop-журнал: `%LOCALAPPDATA%\Tembr\logs\tembr-desktop.log`.
- Для проверки движка без микрофона запусти:
  `backend\venv\Scripts\python.exe backend\smoke_test.py`.
- В режиме разработки сервер по умолчанию доступен на
  `http://127.0.0.1:7860/health`; desktop-окно использует этот же локальный порт,
  чтобы сохранять тему и язык интерфейса между запусками.

## Структура

```text
run.bat                       установка и запуск desktop-приложения
desktop/                      отдельное окно Windows на WebView2
backend/main.py               HTTP API и WebSocket аудио
backend/launcher.py           запуск локального аудиодвижка
backend/model_manager.py      загрузка RVC и адаптация аудио
backend/requirements.txt      закреплённые Python-пакеты
backend/models/               локальные модели, исключённые из Git
frontend/                     интерфейс Tembr Studio и AudioWorklet
```

## Безопасность и лицензии

Исходники Tembr распространяются по MIT License. Desktop-оболочка принимает
только локальную страницу Tembr, разрешает ей микрофон только по действию
пользователя, а другие WebView2-разрешения отклоняет. Локальный сервер слушает
только loopback-интерфейс и не имеет аутентификации. Зависимости и голосовые модели
сторонних авторов имеют собственные лицензии; не загружай модели из источников,
которым не доверяешь.
